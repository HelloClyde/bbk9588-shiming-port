# BBK9588《使命》资料攻略

本目录包含从 S1 版《使命》资源中还原的剧情摘要和野外地图查看器。

## 使用

直接在浏览器打开 `index.html`。地图使用适合网页浏览的 JPEG，支持缩放、拖拽及按地图资源编号切换。

## 大文件

`maps/` 内是 30 张无缝地图，长边限制为 2560 像素、JPEG 质量为 88，合计约 54 MiB，适合直接随攻略提交。

## 说明

- 地图从 `DataLib.dat` / `DataLibIndex.dat` 中的地图和静态物件资源重建。
- 紫色 `#f81f` 已在重建阶段作为透明色处理。
- 部分地图资源尚不能和游戏场景名一一确认，因此查看器保留资源编号，不把未验证的名称写成结论。
